# ☁️ Hybrid Infrastructure Lab

## Project Goal 
Build a simulated business IT environment to develop practical experience with systems administration, networking, cloud technologies, security, and automation.

## 🛠️ Planned Technologies
* VMware
* Windows Server & Active Directory
* Windows 11
* Linux
* DNS & DHCP
* GNS3
* PowerShell
* Python & Ansible
* Microsoft Azure & Entra ID
* Network security and VPN

## 🚧 Project Status
### In Progress
The environment will be built and documented incrementally, including architecture decisions, configurations, validation, automation, and troubleshooting scenarios.
